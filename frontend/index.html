How It Works

From the speaker's mic to the audience's screen in three steps.

1

Start a session

The host logs in, picks a direction, and shares a QR code. Participants join in one tap.

2

Speak naturally

Browser VAD streams only speech to the server, which manages the DeepL Voice connection.

3

Read & hear

Participants see live transcript and translation — and, when enabled, hear it aloud.
